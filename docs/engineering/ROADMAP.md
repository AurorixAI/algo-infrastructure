## Обязательные решения владельца

- question_latex остаётся основным источником. Длина текста не выбирает условие; решённые LaTeX-примеры повторно не исправляем.
- Намеренные деактивации, quarantine рисунков и предусмотренные NULL skill_id сохраняем; неподтверждённые рисунки не включаем автоматически.
- Максимум 42, строгая веткаSE≤0,30 и guarded classification_confident сохраняются как принятый baseline. Новый UI неопределённости не вводим.
- Блок «Единая первопричина не подтверждена» удаляем полностью, существующий процент «надёжности» снимаем. Фактические ошибки, рекомендации и проверки сохраняем.
- LLM-интеграция уже есть. Отсутствие ключа не мешает остальным этапам: полноценный fallback входит в приёмку.
- Исторические очереди и служебные аттестации не объявляем текущими дефектами без свежей проверки. Не перезапускаем массовый платный pipeline автоматически.
- Stage-приёмка не означает публикацию production. Релизы, Git commit/push и оплачиваемые прогоны выполняем в явно разрешённом объёме по действующим правилам проекта.
