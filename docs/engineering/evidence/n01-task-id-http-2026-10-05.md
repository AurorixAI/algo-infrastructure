# N01: точный ID задания в HTTP-загрузке

5 октября 2026. Дефект найден при приёмке w5 после записи банка на stage. Три существующих ID содержат `?`: `G11_TB_?_265`, `G11_TB_?_267_а`, `G11_TB_?_268_а`. Raw URL interpolation переносила суффикс ID в query; content API искал другое значение и возвращал 404. Переименование ID и создание дублирующих заданий не требуется.

Исправлены все обнаруженные task-by-ID потребители: репозиторий диагностики (текущее задание/ответ), журнал ошибок, восстановление Deep Scan, live enrichment отчёта и репозиторий экзамена (замена в черновике). Общий клиент каждого сервиса кодирует ID как URL path segment через стандартный `quote(..., safe="")`; внутренний токен, retry и обработка 404 сохранены. Это поддержка проверенных legacy ID, а не обещание поддержки `/` внутри текущего FastAPI route.

Diagnostic commit: `9c878051be0745e2f4e4f3abf444b32f8c006f3f`; exam commit: `88d91067a5d95504931eb6ef8748c8ffea683fa8`. Ветка CEO; app-deploy автоматически не запускается.

Регрессия воспроизвела 20 отказов до изменения диагностического кода. После исправления 29 диагностических и 8 экзаменационных проверок проходят: три реальных ID, обычный ID, fragment/query delimiters, буквальный percent escape, кириллица/пробелы, отсутствие задания и три пути отчёта. Полный набор: diagnostic **222 passed** на отдельном PostgreSQL/Redis; exam **235 passed** в локальном образе со своими runtime dependencies. Infrastructure **19 passed**. Зависимости экзамена выдают старые deprecation warnings; отказов нет. Эти результаты относятся к локальному коду, не к новому опубликованному image.

Дополнительно настоящие HTTP-запросы прошли к content API из exact-Git content image `sha256:e1d63367ddfab3aaf9b0328b92000532695948ba4d5c81bdaad0046272bbd198` на отдельной PostgreSQL-копии stage DDL и 153 учебных строк: оба непатченных репозитория загрузили все 22 ID; диагностический журнал ошибок получил все 22 условия и ключа. База в этой проверке содержала исходные учебные строки после rollback drill: это доказательство точной загрузки ID, не новая приёмка исправленного содержания.
